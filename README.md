# شرکت راهبردی زمین و ملک ایرانیان

وب‌سایت ایستا و راست‌چین هلدینگ. صفحه معرفی اولیه از صفحات داخلی مستقل نگه داشته شده است.

## نقشه فایل‌ها

- `index.html` — صفحه معرفی و ورود به هلدینگ
- `home.html` — صفحه اصلی داخلی
- `about.html` — معرفی هلدینگ
- `groups.html` — فهرست گروه‌های تخصصی
- `projects.html` — پروژه‌ها
- `contact.html` — ارتباط با هلدینگ
- `groups/` — صفحات جزئی حوزه‌های تخصصی
- `assets/css/internal-polish.css` — یکپارچه‌سازی ظاهر صفحات داخلی، منو و فوتر
- `assets/js/internal-polish.js` — منوی مشترک، فوتر مشترک، ناوبری موبایل و بازگشت به بالا
- `assets/fonts/` — فایل‌های فونت
- `logo.png` — نشان هلدینگ

## قواعد لینک‌دهی

1. لینک‌های صفحات اصلی از ریشه مخزن با مسیر نسبی مانند `home.html` استفاده می‌کنند.
2. صفحات داخل `groups/` برای رسیدن به صفحات اصلی از `../` استفاده می‌کنند.
3. فایل‌های مشترک در صفحات ریشه از `assets/...` و در صفحات گروه‌ها از `../assets/...` فراخوانی می‌شوند.
4. برای حفظ لینک‌های GitHub Pages، صفحات اصلی فعلاً در ریشه و صفحات تخصصی در `groups/` نگه داشته شده‌اند؛ انتقال بی‌برنامه آن‌ها به پوشه جدید می‌تواند لینک‌های منتشرشده را خراب کند.
